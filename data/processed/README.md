# Processed Data

Normalized and enriched tables generated by notebooks or scripts are produced here.

These files are reproducible and should not be treated as the source of truth.

The current primary source is the `Data` sheet in the original Excel workbook. Generate the prepared table with:

```powershell
python scripts/prepare_data.py "data/raw/Pharm Data.xlsx" "data/processed/transactions_normalized.csv"
```

The CSV remains available for comparison and uses `cp1252` encoding.
The Excel workbook repairs several city and region names. The `Demo` and `Sheet3`
sheets are used as reference tables to fill missing populations and regions when
a `City` or `Country + City` match is available. Negative sales and duplicates are
kept and documented instead of being silently corrected.
