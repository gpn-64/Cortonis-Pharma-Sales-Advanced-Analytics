# data

- `raw/` — source brute, telle qu'extraite. **Non versionnée** (volumineuse et tierce) — voir [.gitignore](../.gitignore) et [raw/README.md](raw/README.md).
- `processed/` — données normalisées et enrichies, reproductibles via `scripts/prepare_data.py`. Non versionnées.
- Pas de dossier `data/sample/` : le jeu de données est un jeu public de Foresight, téléchargeable directement depuis [la source](https://foresightbi.com.ng/practice-data/3-datasets-for-your-portfolio/).
